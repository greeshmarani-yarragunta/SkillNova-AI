# SkillNova AI

AI-powered technical skill assessment and career-readiness platform built with React and Django.

## Features

- Student, Instructor, and Admin roles
- 30-question technical assessments
- AI-powered question generation
- AI Assistant for technical queries
- Skill-wise performance analysis
- Interview preparation
- Resume Analyzer
- Question Bank management
- Student performance tracking
- Notifications
- Role-based authentication and access control

## Tech Stack

**Frontend:** React, Vite, JavaScript  
**Backend:** Django, Django REST Framework  
**Database:** SQLite (development), MySQL (production)  
**Authentication:** JWT  
**AI:** Gemini API / Intelligent Heuristic Engine
